Download Dagu worker

Remote execution uses a pinned Dagu worker — install it on the computer that contains the remote KRE, then connect it to TestOrchestrator's Dagu coordinator. Sequence: install KRE on the test computer → install the Dagu worker → connect securely to the coordinator → register the KRE installation here with the worker's label → verify → execute.

Worker setup instructions

On the computer containing the remote KRE:

# 1. Download + verify (sha256 must match the value above)
tar xzf dagu_{{ dagu_assets[0].version }}_<os>_amd64.tar.gz

# 2. Start the worker, labeled uniquely for this installation.
#    The coordinator address must be reachable FROM the worker —
#    use this portal's configured Dagu coordinator address, never
#    "localhost" for a different computer. Example:
./dagu worker --worker.coordinators=<portal-host>:50055 \
  --worker.labels kre=<unique-label> --worker.id <worker-name>

# 3. Register the KRE installation above as "On another machine"
#    with the same kre=<label>.

The worker polls outbound to the coordinator — no inbound port is needed on the KRE machine. Keep the coordinator's authentication enabled on real deployments; worker credentials are configured per-worker, never embedded in this download.
