Git — evidence export repository (optional)

Optional Git destination for explicitly-requested evidence exports (non-force pushes). Not required for ordinary evidence retention or reporting — leaving it unset does not disable local artifact storage, log/screenshot viewing, or Allure report generation/viewing; the local evidence store is authoritative. Export credentials and write access are separate from source-repository access. Runs under the Dulwich backend; HTTPS uses a Secret with user:pass content, SSH uses host ssh/agent.


Destination repo path or URL for evidence pushes. Local path, https://, or ssh:// / SCP-like. Empty = export disabled.

Secret reference used for HTTPS pushes (expects user:password content). Required only for authenticated remotes; local paths and agent-based SSH need none.

Branch the evidence repo tracks. Default: main.
Example
git_export_repo: /srv/evidence/export-repo
git_export_credential_ref:            # none needed for a local path
git_export_ref: main

Allure is configured under System → Reporting; network/bind settings under System → Network.
