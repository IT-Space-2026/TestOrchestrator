Dagu — orchestration

Coordinates dispatch of executions to workers. Required when Dagu is the mandatory orchestrator; executions queue until reachable. Empty = not configured (local dispatch only where the deployment permits it).


Base URL of the Dagu server. Format: http(s)://host[:port]. Used by the dispatch worker; applies to future dispatches.

Reference to a stored secret (bearer token, or password when basic-auth username is set). Required only if the Dagu server enforces auth. Never the secret value itself.

Empty = bearer-token auth against the credential; non-empty = HTTP basic auth (username + credential secret).
Example
dagu_endpoint: https://dagu.internal:8080
dagu_credential_ref: dagu-api-key   # a Secret named 'dagu-api-key'
dagu_username:                      # empty → bearer-token mode

Git — evidence export repository

Internal export repo receiving execution evidence pushes (non-force). Optional — local artifact storage always works without it. Runs under the Dulwich backend; HTTPS uses a Secret with user:pass content, SSH uses host ssh/agent.


Destination repo path or URL for evidence pushes. Local path, https://, or ssh:// / SCP-like. Empty = export disabled.

Secret reference used for HTTPS pushes (expects user:password content). Required only for authenticated remotes; local paths and agent-based SSH need none.

Branch the evidence repo tracks. Default: main.
Example
git_export_repo: /srv/evidence/export-repo
git_export_credential_ref:            # none needed for a local path
git_export_ref: main

Allure is configured under System → Reporting; network/bind settings under System → Network.
