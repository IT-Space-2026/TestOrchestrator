Example — accepted configuration
allure_java_home: /usr/lib/jvm/java-17-openjdk-amd64   # JAVA_HOME dir…
                  /usr/bin/java                         # …or java binary path
allure_enabled:   checked

Java home vs executable: the field accepts either a JDK/JRE home directory (like JAVA_HOME — the bin/java inside it is used) or the path to the java executable itself. Platform note: paths are host-specific — on the packaged Linux target a JDK/JRE installed by the distro or unpacked to e.g. /opt/java/openjdk is expected; Windows paths are not valid on this target. Enablement: the checkbox turns generation on; without a validated runtime generation still fails — enabling does not substitute for a working Java. Probe: saving a path or pressing Check readiness runs a real Allure report-generation probe with the bundled generator — pass/fail is recorded and shown under Readiness. Changes apply to future generations; existing reports are unaffected.
