reporting-labs

Self-contained interactive report (embedded data + IT-Space branding). Works offline and in downloaded zips. Generations are published atomically; the newest three generations are retained for in-flight readers.

Enabled by default

Bundled runtime vs system tools: report generation uses the package's own Python runtime — no customer-installed Node, npm, or external generator is needed and no extra download runs at report time.
