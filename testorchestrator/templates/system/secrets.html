Secret values are stored encrypted (key held outside the database) and are never returned to this page, logs, or Git exports. Other configuration references them by name only.

Kinds: generic — opaque value used by integrations that take a token/key; user:password — HTTPS Git credentials (Git export repo, source bindings); api-token — Dagu bearer token; and worker/agent tokens (issued under Infrastructure). Reference them from System → Integrations via the credential ref fields. Required: name (unique, letters/digits/-/_), kind, value. Description is optional metadata.

Example — create + reference
Store credential:  name=dagu-api-key  kind=api-token
                   value=<token value — never shown again>
                   description=Dagu server bearer token
Reference:         System → Integrations → Dagu credential ref
                   = dagu-api-key
Git export:        name=git-https-push  kind=user:password
                   value=<user:pat>
                   referenced by Git export credential ref

Editing later: the stored value is never re-displayed; the value field starts blank — leave it blank to keep the existing secret, or enter a new value to rotate it.
